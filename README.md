# heresale-data

여긴할인 앱이 켜질 때 받아 가는 최신 혜택 자료입니다. (공개된 카드·통신사·지역화폐 혜택, 프랜차이즈 이벤트, 카드 포인트 사용처)

| 파일 | 내용 |
|---|---|
| benefits.json | 카드·통신사·지역화폐 혜택 |
| promos.json | 프랜차이즈·간편결제 기간 이벤트 |
| points.json | 카드 포인트(현대카드 M포인트 등) 매장 사용처 |

- 예약 작업(매일 오류 점검, 매주 점검, 매달 재확인)이 고친 내용을 여기에 올립니다.
- 앱은 jsDelivr → GitHub 원본 순서로 받아, 앱에 든 자료보다 `meta.version`/`meta.checkedAt`이 새로울 때만 씁니다. 고장 난 파일이면 앱에 든 자료를 씁니다.
- 올리기 전 `python3 check.py`로 형식을 검사합니다.
