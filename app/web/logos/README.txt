[업체 로고 넣는 방법]
1. 각 브랜드에서 받은 공식 로고 이미지(정사각형 PNG/SVG 권장, 128x128 이상)를 이 폴더에 넣습니다.
   예) logos/starbucks.png
2. data/logos.json에 브랜드 이름과 경로를 적습니다. 브랜드 이름은 앱에 표시되는 이름과 똑같이 적어야 합니다.
   예) { "스타벅스": "/logos/starbucks.png", "GS25": "/logos/gs25.png", "삼성카드": "/logos/samsungcard.png" }
3. 로고 파일이 없거나 열리지 않으면 앱이 자동으로 업종 색 배지(글자)로 대신 보여 줍니다.

※ 로고는 각 회사의 등록상표입니다. 상업용 앱에 쓰려면 상표권자의 허락(제휴 계약, 브랜드 가이드 동의 등)을 받아야 합니다.
   인터넷에서 찾은 로고 이미지를 허락 없이 넣으면 상표권 침해 문제가 생길 수 있어요.
   제휴 요청 시 "매장 위치·할인 정보 안내 목적의 로고 표시"로 문의하면 됩니다.
