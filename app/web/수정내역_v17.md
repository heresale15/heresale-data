## 새로 생긴 것
- `app/` : Capacitor 7 안드로이드 앱 프로젝트 (앱 ID `kr.heresale.app`, 이름 "여긴할인")
  - `npm run add-android`, `npm run sync`로 web 폴더를 앱에 넣고 위치·알림 권한을 자동으로 추가
  - 아이콘 원본 `app/assets/`

## 앱에서만 동작하는 기능 (웹에서는 그대로)
- **위치 권한**: 휴대폰 권한 창으로 요청. 거부하면 설정 경로 안내
- **월말 알림** (내 지갑 → 월말 알림 받기)
  - 25일 저녁 8시: 카드별 전월실적까지 남은 금액이나 남은 할인 한도 (결제 기록 기준)
  - 1일 아침 10시: 지난달 절약 리포트 안내
  - 결제 기록을 남기거나 지우거나, 앱으로 돌아올 때마다 알림 내용 갱신
- **뒤로가기 버튼**: 시트 → 매장 화면 → 목록 탭 → 앱 종료 순서
- **바깥 링크**: 카카오맵·네이버·카드 정보 링크를 앱 안 브라우저로 열기
- **최신 혜택 데이터**: 실행할 때 사이트의 benefits.json을 먼저 받고, 안 되면 앱에 들어 있는 데이터 사용 → 데이터 수정은 사이트 배포만으로 앱에 반영

- 원본: 공공데이터포털 "부산광역시_지역화폐(동백전) 가맹점 현황" 163,422건 (기준일 2026-04-24)

- 공공데이터에 이름이 있는 매장은 "보통 가맹점 아님" 제외 규칙보다 데이터를 따름 (예: 가맹점으로 등록된 다이소 매장)

- 실제 가맹점 3,000곳 표본 → 2,999곳 "가맹점 확인" (1곳은 결제대행 항목 "티머니 onda_가승인")
