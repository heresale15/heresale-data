# 여긴할인 v16 수정 내역 (2026-11-17)

## 1. 업체 로고
- `data/logos.json`에 브랜드별 이미지 경로를 넣으면 글자 배지 자리에 로고가 표시됨 (목록·지도·상세 공통).
- 이미지가 없거나 깨지면 자동으로 기존 글자 배지로 표시.
- 로고 파일은 포함하지 않음: 각 브랜드 상표라서 사용 허락을 받은 파일만 `logos/`에 넣어야 함 (`logos/README.txt`).

## 2. 카카오 길찾기 → 카카오맵
- 매장 상세 버튼을 [카카오맵]으로 변경. 카카오맵의 해당 매장 페이지(장소 상세)로 열림.

## 3. 지역화폐·상품권
- 내 지갑에 [지역화폐·상품권] 추가: 동백전, 온누리상품권(디지털), 인천e음, 서울사랑상품권, 경기·대구·광주·대전·울산·세종·강원·충북·충남·전북·전남·경북·경남·제주 (18종).
- 확인된 기본 할인율: 동백전 10%(월 5만원 한도), 인천e음 10%(월 3만원), 서울사랑 5%, 온누리 디지털 7%. 나머지는 지역·시군·시기별로 달라 사용자가 할인율을 직접 입력.
- 매장 주소로 지역을 판별해 다른 지역 화폐는 계산에서 제외. 대형마트·대기업 직영 브랜드는 '보통 가맹점 아님'으로 제외.
- 가맹점 여부는 매장마다 달라 '가맹점일 때'라고 표시. 목록 화면의 1만원 기준 할인액에는 넣지 않음(카드·통신사만).
- 카드와 비교해 더 큰 쪽을 2단계 결제수단으로 추천. 내 지역과 켜 둔 것만 먼저 보이고 나머지는 접어 둠.

## 4. 카드 목록·검색
- 혜택 확인 카드 21종 + 실제 판매 카드 이름 목록 58종 (`data/cards_catalog.json`, 12개 카드사).
- 카드사 칩, 신용/체크 필터, 초성 검색(예: ㅌㅌ → taptap 계열) 지원.
- '혜택 확인 전' 카드는 [내 카드로]를 누르면 이름·카드사·종류가 채워진 입력창이 열리고, 할인율만 넣으면 계산됨.
- 시중 모든 카드를 다 넣지는 못함: 혜택을 확인하지 않은 할인율을 넣으면 틀린 정보가 되므로, 이름 목록과 확인 카드를 매달 늘리는 방식.

## 5. 카드 발급 안내
- 매장 상세 [이 카드면 더 아껴요]: 안 가진 카드 중 지금 최선보다 더 할인되는 카드 최대 3개, 차액 표시, [카드 알아보기] 버튼.
- 내 지갑 [내 결제 기록으로 보면]: 이번 달(없으면 지난달) 결제 기록 기준으로 더 아꼈을 카드 추천 (3건 이상 기록 시).
- 월 한도가 확인된 혜택만 추천 (한도 미상 카드는 할인액이 부풀려질 수 있어서 제외).
- 기본은 비교 정보(제휴·수수료 없음). `CONFIG.cardPromo.affiliate`를 켜면 제휴 링크, [광고] 표시, 심의필 번호가 나옴.
- 신용카드 경고문 항상 표시.

## 6. 본인인증·카드 내역 → 결제 기록으로 대체
- 본인인증으로 카드 내역을 가져오려면 마이데이터 허가가 필요해 이번 버전에서는 직접 기록 방식으로 구현.
- 매장 화면 [이렇게 결제했어요] → 금액·결제수단 저장 (기기에만 보관).
- 카드별로 이번 달 결제액, 받은 할인, 남은 월 한도, 다음 달 전월실적 진행률, 지난달 실적 충족 여부 표시.
- 남은 한도가 할인 계산에 바로 반영되고, 한도를 다 쓰면 다른 카드나 지역화폐를 추천.
- 직접 추가 카드에 전월실적 입력란 추가.
